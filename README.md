# ريش — Rish

موقع عربي متكامل للعناية بالطيور وتربيتها، بتصميم هادئ مستوحى من الطبيعة ودعم كامل للغة العربية واتجاه RTL.

## الصفحات

| الصفحة | المحتوى |
| --- | --- |
| `index.html` | الرئيسية: تعريف بالموقع، الأنواع، مزايا المحتوى، النشرة البريدية |
| `types.html` | أنواع الطيور، اختبار ترشيح تفاعلي، جدول مقارنة |
| `care.html` | دليل العناية: التغذية، النظافة، الاستحمام، تجهيز القفص، قائمة يومية |
| `health.html` | الصحة والوقاية، علامات المرض، الإسعافات الأولية، السموم |
| `breeding.html` | التربية والتكاثر: اختيار الزوج، التعشيش، الحضانة والفطام |
| `contact.html` | نموذج تواصل تجريبي وأسئلة شائعة |
| `credits.html` | مصادر الصور والمصورون والتراخيص |

## التشغيل محليًا

```bash
python -m http.server 8765
```

ثم افتح <http://127.0.0.1:8765>.

## التقنيات

- HTML5 وCSS3 وJavaScript بدون أي إطار عمل أو خطوة بناء.
- خطا Google Fonts: Tajawal وAmiri.
- صور محلية محسّنة داخل `assets/img`، مع توثيق كامل في `credits.html`.

## ملاحظات

- نموذج التواصل تجريبي ولا يرسل بيانات فعلية.
- الصور من Flickr وWikimedia Commons وفق تراخيص المشاع الإبداعي أو الملكية العامة؛ راجع `credits.html` قبل إعادة استخدام أي صورة.
- النصوص محررة خصيصًا لهذا المشروع.

## النشر

الموقع ثابت بالكامل وجاهز للنشر على GitHub Pages أو أي استضافة ملفات ثابتة.
